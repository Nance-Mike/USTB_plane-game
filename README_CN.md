# 飞机大战 (Plane War)

基于 Windows 控制台 API 实现的经典射击游戏，使用 C++ 编写，采用 ASCII 字符画风格，具有流畅的游戏体验、动态难度系统和完整的 UI 界面。

## 项目结构

| 文件 | 说明 |
|------|------|
| `plane_war.cpp` | 基础版，包含核心游戏机制 |
| `enhanced_plane_war.cpp` | 增强版，包含菜单、难度递增、暂停和结算界面 |
| `plane_war.exe` | 基础版编译程序 |
| `enhanced_plane_war.exe` | 增强版编译程序 |

## 功能特性

### 增强版 (`enhanced_plane_war.cpp`)

- **多界面系统** — 主菜单、帮助页面、暂停覆盖层、结算界面
- **动态难度** — 随着分数提高，敌机移动更快、刷新更频繁、射击概率更高
- **边界保护** — 玩家飞机不能飞出游戏区域
- **碰撞检测** — 飞机、子弹与玩家之间的像素级碰撞判定
- **暂停系统** — 随时按 ESC 暂停/恢复游戏
- **计分系统** — 初始 5 分，击中敌机 +1，被击中 -1，分值归零则游戏结束
- **重玩支持** — 每局结束后可重新开始或返回主菜单

### 基础版 (`plane_war.cpp`)

- 基础射击与移动机制
- 简单的刷新和碰撞系统
- 胜负判定

## 编译方法

需要 Windows 环境和 C++ 编译器（如 MSVC、MinGW）。

```bash
# 使用 g++ (MinGW)
g++ -o plane_war.exe plane_war.cpp
g++ -o enhanced_plane_war.exe enhanced_plane_war.cpp

# 使用 MSVC (开发者命令提示符)
cl enhanced_plane_war.cpp
```

> **注意：** 游戏使用了 Windows 专有头文件（`<windows.h>`、`<conio.h>`），不支持跨平台编译。

## 运行方法

```bash
./enhanced_plane_war.exe
```

运行后将打开一个 86x48 的控制台窗口，使用键盘操作即可开始游戏。

## 操作说明

| 按键 | 功能 |
|------|------|
| W / A / S / D | 上 / 左 / 下 / 右 移动 |
| 空格键 | 发射子弹 |
| ESC | 暂停 / 恢复 |
| Q | 退出当前回合 |
| B | 返回（帮助界面） |
| 1 / 2 / 3 | 菜单选择（开始 / 帮助 / 退出） |
| Y / N | 再来一局 / 返回主菜单（结算界面） |

## 游戏规则

1. 击毁敌机获得分数（每击毁一架 +1 分）。
2. 玩家被敌机子弹命中或与敌机碰撞，分数 -1。
3. 游戏初始拥有 5 分，当分值降为 0 时游戏结束。
4. 随着分数升高，难度逐步提升：
   - 敌机下落速度加快
   - 敌机刷新间隔缩短
   - 敌机射击概率增大
5. 全部击毁 50 架敌机即可获胜。

## 难度等级

| 等级 | 分数区间 | 敌机速度 | 刷新间隔 | 射击概率 |
|------|----------|----------|----------|----------|
| 1 | 0-6 | 慢 | 12 帧 | 2% |
| 2 | 7-9 | 中等 | 10 帧 | 3% |
| 3 | 10-14 | 快 | 8 帧 | 4% |
| 4 | 15-19 | 较快 | 6 帧 | 5% |
| 5 | 20+ | 最快 | 4 帧 | 6% |

## 技术实现

- **渲染**：使用 `SetConsoleCursorPosition` 实现双缓冲画布绘制，消除闪烁
- **游戏循环**：固定时间步长，每帧约 50ms（20 FPS）
- **碰撞检测**：基于像素的包围盒碰撞判定
- **面向对象设计**：`Plane` 基类，`PlayerPlane` 和 `EnemyPlane` 子类；`Game` 类管理所有状态和逻辑
